# 📊 Ferramenta de Controle de Investimentos

Este repositório contém uma planilha desenvolvida como atividade prática do bootcamp **Reclame AQUI - Dados e IA na Prática**, em parceria com a **Digital Innovation One (DIO)**.

A proposta da ferramenta é auxiliar no controle e organização de investimentos pessoais, permitindo acompanhar valores aplicados, rendimentos e evolução do patrimônio ao longo do tempo.

## 🎯 Objetivo

O objetivo deste projeto é criar uma ferramenta simples e funcional para:

- registrar investimentos realizados;
- acompanhar aportes mensais;
- monitorar rentabilidade e desempenho;
- visualizar o crescimento do patrimônio;
- organizar dados financeiros de forma clara e prática.

A planilha pode ser utilizada como uma base inicial para gestão de investimentos, especialmente para quem está começando no mercado financeiro.

## 📌 Funcionalidades

A ferramenta foi pensada para facilitar a análise e o controle de investimentos por meio de uma planilha em Excel. Entre as possibilidades de uso, destacam-se:

- cadastro de investimentos;
- acompanhamento de valores investidos;
- visualização de rendimento ou ganho;
- controle de aportes recorrentes;
- organização dos dados em uma estrutura clara;
- suporte para análise financeira pessoal.

## ⚙️ Como funciona

A planilha foi estruturada para permitir a inserção de dados básicos relacionados aos investimentos, como:

- valor investido;
- tipo de ativo ou aplicação;
- data da aplicação;
- rendimento estimado;
- valor total acumulado;
- acompanhamento do desempenho ao longo do tempo.

Com isso, o usuário consegue manter uma visão geral da sua carteira e avaliar melhor sua evolução financeira.

## 🧮 Conceitos aplicados

Este projeto trabalha com conceitos essenciais de organização financeira e análise de dados, como:

- controle de investimentos pessoais;
- organização de informações em planilhas;
- acompanhamento de patrimônio;
- análise de performance financeira;
- uso de fórmulas e cálculos em Excel;
- estruturação de dados para facilitar leitura e manutenção.

## 🖼️ Estrutura do projeto

O repositório contém:

- uma planilha em Excel com a ferramenta de controle de investimentos;
- um arquivo `README.md` com a documentação do projeto.

## 🚀 Como usar

1. Faça o download da planilha disponível neste repositório;
2. Abra o arquivo no Microsoft Excel;
3. Preencha os campos com as informações dos seus investimentos;
4. Atualize os valores e acompanhe o desempenho ao longo do tempo;
5. Utilize os dados para avaliar a evolução do seu patrimônio.
